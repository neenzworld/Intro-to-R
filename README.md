# Econometric Workbooks Library in R & Quarto

A comprehensive, production-grade econometric workbook library built using **R** and **Quarto**. This repository covers fundamental to advanced econometric, causal inference, spatial, and high-dimensional machine learning workflows using global life expectancy panel data from *Our World in Data* (OWID).
